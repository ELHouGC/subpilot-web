
# SubPilot Web

Vue frontend for SubPilot, a subscription-based SaaS integration prototype.

## Technology

- Vue 3
- TypeScript
- Vue Router
- Pinia
- Supabase JavaScript SDK

## Responsibilities

- User registration and authentication.
- Subscription and pricing interface.
- Protected application routes.
- Realtime notification interface.

## Development

```bash
npm install
npm run dev
```

## Environment

Create `.env.local`:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
VITE_API_BASE_URL=http://localhost:3000
```
